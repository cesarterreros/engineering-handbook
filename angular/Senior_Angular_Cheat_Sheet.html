Senior Angular & RxJS: Complete Technical Interview Cheat Sheet

Modern Architecture & DI

  • Standalone Components: The modern default (Angular 14+). Eliminates NgModules. Dependencies are imported directly via the imports: [] array in the @Component decorator.
  • The inject() Function: Modern alternative to constructor injection. Enables functional guards, functional interceptors, and reusable logic blocks outside of classes.
  • Dependency Injection (DI): providedIn: 'root' creates a global singleton. providedIn: 'any' creates a unique instance per lazy-loaded module.
  • Resolution Modifiers:
    • @Optional(): Prevents errors if a service isn't found.
    • @Self(): Restricts lookup to the element's own injector.
    • @SkipSelf(): Bypasses the local injector, checking parents.

Signals & Reactivity (Angular 16+)

  • Signals: Provide fine-grained, synchronous reactivity. Replaces many RxJS use cases and fixes the "Diamond Problem" (glitch-free state evaluation).
  • Core APIs: signal() for writable state, computed() for derived read-only state, effect() for tracking side-effects.
  • model() API: Replaces standard @Input/@Output pairs for seamless, signal-driven two-way data binding.

Change Detection & Performance

  • OnPush Strategy: (ChangeDetectionStrategy.OnPush) Skips component checks unless an @Input reference changes, an event is triggered locally, or an AsyncPipe emits.
  • NgZone & Zoneless: Angular historically uses zone.js to monkey-patch async browser events. Use runOutsideAngular() to execute heavy 3rd-party scripts without triggering change detection. Angular 18+ is moving toward fully Zoneless applications relying strictly on Signals.
  • SSR & Hydration: Server-Side Rendering provides static HTML for fast Largest Contentful Paint (LCP). Incremental Hydration makes blocks interactive asynchronously.
  • TrackBy / @for track: Essential for avoiding full DOM re-renders when rendering lists.

Component Communication & Forms

  • Parent/Child: @Input() pushes data down; @Output() emits events up.
  • ControlValueAccessor (CVA): The standard interface required to build custom form components that integrate seamlessly with Angular's Reactive Forms API (perfect for complex, dynamic UIs).
  • Reactive Forms: Logic-driven, scalable forms using FormGroup and FormControl. Supports Synchronous and Asynchronous validators (e.g., checking backend databases for username uniqueness).

Template Queries & DOM

  • @ViewChild: Direct access to a child component instance or raw DOM element via ElementRef.
  • @ViewChildren: Returns a dynamically updating QueryList.
  • The "ng" Quartet:
    • <ng-template>: Unrendered blueprint.
    • <ng-container>: Ghost wrapper (zero DOM footprint).
    • <ng-content>: Content projection portal.
    • *ngTemplateOutlet: Dynamic renderer.
  • *ngComponentOutlet: Programmatically instantiates dynamic components at runtime.

Routing, Guards & Deferrable Views

  • Module-Free Routing: loadComponent loads standalone components; loadChildren points to route arrays, bypassing wrapper modules.
  • Functional Guards: CanActivateFn replaces class-based guards for concise route protection (e.g., checking JWT token claims before accessing a route).
  • Wildcard Route (**): Must be the absolute last route defined.
  • Deferrable Views (@defer): Template-level lazy loading.
    • @placeholder: Eager initial UI.
    • @loading: Shows during chunk download.
    • @defer: Core block (Triggers: idle, interaction, viewport).
    • Anti-pattern: Avoid nesting defer blocks to prevent cascading load delays.

Advanced RxJS & API Integration

  • Higher-Order Observables:
    • switchMap: Cancels previous requests (Live Search).
    • mergeMap: Runs all in parallel (Analytics/Logging).
    • concatMap: Queues sequentially (Ordered Saves).
    • exhaustMap: Ignores new requests until the current finishes (Login Buttons).
  • Memory Management: Prevent leaks using takeUntilDestroyed() (injecting DestroyRef) or delegating subscription entirely to the AsyncPipe in the template.
  • Functional Interceptors: Act as middleware checkpoints (e.g., dynamically injecting Bearer JWTs into headers). Registered via provideHttpClient(withInterceptors([...])).

State Management (NgRx)

  • Actions: Describe specific events triggered by the UI.
  • Reducers: Pure functions that use the spread operator (...state) to mutate data safely, returning a new immutable state tree.
  • Selectors: Read-only, memoized lenses that slice specific state for components.
  • Effects: RxJS streams handling asynchronous side-effects (e.g., Web API HTTP calls).

TypeScript for Full-Stack Ecosystems

  • Safe Navigation: Optional Chaining (?.) and Nullish Coalescing (??).
  • Utility Types: Pick<Type, Keys> and Omit<Type, Keys> are highly effective for mapping backend C# DTOs to strict frontend representations.
  • Type Assertions: Use as Type to override compiler assumptions.
  • Generics: <T> ensures reusable, type-safe API service methods.

⚡ Async Reactivity: Resource API (Angular 19–20)

  • resource(): Bridges signals to async data. Re-runs a loader when its params signal changes; exposes value(), status(), error(), and isLoading() as signals.
  • rxResource(): Same pattern, but the loader returns an Observable (stream) — enables resource streaming. Import from @angular/core/rxjs-interop.
  • httpResource(): Reactive wrapper around HttpClient; returns request status + response as signals. Supports interceptors. (Experimental in v20.)
  • Key win: Built-in loading/error states + automatic request cancellation — replaces manual switchMap + subscription boilerplate for data fetching.

🎯 Signal-Based Inputs & Queries

  • input() / input.required(): Signal inputs; read as myInput(). Support transform, aliases, and are read-only in the child.
  • output(): Function-based replacement for @Output() EventEmitter.
  • viewChild() / viewChildren() / contentChild() / contentChildren(): Signal query functions; the .required variant guarantees a match. Available reactively before ngAfterViewInit.
  • linkedSignal(): Writable signal derived from other signals that resets when its source changes (e.g., a selected item that clears on list reload).
  • Migration: Official ng generate @angular/core:signal-queries / VSCode refactor exists.

🧩 Directive Composition & Custom Directives

  • hostDirectives: Reuse behavior by attaching directives to a component's host without inheritance; host directives run their hooks before the host component.
  • 3 Directive Types:
    • Component: Has a template.
    • Attribute ([appX]): Changes behavior/look.
    • Structural (*): Reshapes the DOM.
  • host metadata: Modern way to bind host properties/listeners (preferred over @HostBinding/@HostListener).

🔀 Built-in Control Flow (Angular 17+)

  • Blocks: @if / @else if / @else, @for (item of items; track item.id) (⚠️ track is mandatory), @switch / @case / @default.
  • @let: Declare template-local variables (Angular 18.1+).
  • Why: Faster, no *ngIf/*ngFor imports needed, up to ~90% faster runtime for list updates. The @empty block handles empty collections.

🖥️ SSR, Hydration & Rendering Modes

  • Non-destructive Hydration: Reuses server DOM instead of re-rendering; enable via provideClientHydration().
  • Incremental Hydration: @defer (hydrate on ...) hydrates blocks lazily. (Angular 19+)
  • Event Replay: withEventReplay() captures user events during hydration and replays them once interactive.
  • Hybrid Rendering: Per-route RenderMode (Server / Client / Prerender) via provideServerRendering + route config.

🧪 Testing Essentials

  • Setup: TestBed.configureTestingModule + ComponentFixture; fixture.detectChanges() triggers change detection.
  • Async: fakeAsync + tick() for timers; flush() drains the macrotask queue.
  • HTTP: provideHttpClientTesting() + HttpTestingController to mock/expectOne/flush requests.
  • Harnesses: Angular CDK Component Harnesses for robust, implementation-agnostic component tests.

🔐 Security & Best Practices

  • Built-in XSS Protection: Angular auto-sanitizes interpolation & bindings by context.
  • DomSanitizer + bypassSecurityTrust...(): Use only with fully trusted content.
  • Trusted Types: CSP-level defense against DOM XSS.
  • Rule of thumb: Avoid innerHTML with untrusted data; never concatenate user input into templates.
